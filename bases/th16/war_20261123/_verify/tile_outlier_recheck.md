## ② 手算推导（完整中间值）

### 例 1：14_kekejdj 旋转炮，image_px=(457,130)，记录 (0,5)

quad：T(520,110) / R(905,345) / B(512,555) / L(150,350)。

西边界 = T→L 直线。求该线在点 x=457 处的 y：

```
y_TL = 110 + (350−110) × (457−520)/(150−520)
     = 110 + 240 × (−63)/(−370)
     = 110 + 40.9 = 150.9
```

点 y=130 < 150.9，即点在 TL 线以北（菱形外侧一侧）20.9px。单应反算 `px_to_tile(457,130)=(−1.842, 5.044)`：gx 负、gy≈5，与线面判断一致——**点在所选西边界外侧**。
但目视原图（`scratch/p14.png` 裁切复核）：红点压在一栋深蓝旋转炮真建筑上，建筑位于北墙线贴边，不是读错物体。故负格来自 quad 左/上角点内收把腰线画到了建筑内侧 → **(a)**。

### 例 2：16_diddieyang 左防空，image_px=(231,268)，记录 (0,27)

quad：T(508,105) / R(925,365) / B(508,560) / L(95,360)。

```
y_TL = 105 + (360−105) × (231−508)/(95−508)
     = 105 + 255 × (−277)/(−413)
     = 105 + 171.1 = 276.0
```

点 y=268 < 276.0，线以北 8.0px，单应反算 `(−0.652, 27.278)`，gx 微负。
目视原图（`scratch/p16.png`）：红点落在两栋金顶防空之间的**草地空地**，未压任何建筑——偏差 8px 的线外只是表象，真问题是手读点本身落空 → **(c)**。

（另两例同法：15 鹰炮 TL 线在 x=406 处 y=174.8，点 y=160，线以北 14.8px，反算 (−1.220, 9.419)，点压金红鹰炮真建筑 → (a)；17 鹰炮 TL 线在 x=453 处 y=134.2，点 y=127，线以北 7.2px，反算 (−0.563, 3.881)，点落顶部草地 → (c)。）

## § 菱形比例自检（追加，纯读+手算，未改任何数据）

### 判据与实测

尝试从原图独立量出真实菱形宽:高：① 单栋建筑底座像素宽:高（14 大本、14 左防空、15 鹰炮、17 左防空等放大裁 4×+10px 网格逐栋看）——底座被塔体/阴影/相邻墙遮挡，压不到可读数的菱形四角，**量不出可信数值**；② 相邻城墙段步长——图上无明确 1 格刻度，无法定标；③ 外轮廓长宽比——即 quad 本身，循环论证，不能作独立判据。

### 结论一句话
