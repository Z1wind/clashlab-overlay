快捷键与标注流程

鼠标左键点建筑＝选中；点空白＝用当前类型新增一栋；按住拖动＝移动位置
鼠标右键删除鼠标下的建筑（可撤销）
滚轮缩放（以鼠标为中心）
1–9选常用类型；若已选中建筑则直接改它的类型
方向键选中建筑微调 1 格
Tab / Shift+Tab下一栋 / 上一栋（自动滚动到可见）
Delete删除选中建筑
Backspace / Ctrl+Z撤销上一步
Ctrl+S立即保存（平时改动后 1.2 秒自动保存）
Enter保存并进入下一阵
Space保存并标记「跳过」，进入下一阵
Q / E上一候选 / 下一候选方案
PageUp / PageDown上一阵 / 下一阵
R 两次重置当前阵为 layout.json 预填
G进入/退出「校准网格」：拖 4 个角点（上/右/下/左）对齐整张 44×44 地图的最外圈格边界（不是最外侧建筑/墙）；方向键 ±1px、Shift+方向键 ±10px；Enter 应用 / Esc 取消
Esc取消选中 / 关闭本帮助

减少工作量的推荐流程

1. layout.json 已预填好建筑框（红＝防御、金＝大本营、紫＝部落城堡、绿＝资源、蓝＝兵营）。
2. 逐个核对：位置不对就拖动方框；类型不对就选中它再点调色板（或按 1–9）。
3. 预填漏掉的建筑：用当前类型点它应该在的格子即可补录；多出来的按 Delete 删掉。
4. 一栋都没问题的阵直接按 Enter 保存并下一阵；不想标的按 Space 跳过。
5. 若发现预填整体偏/斜（quad 不贴合地图边界），按 G 进「校准网格」：拖 4 个角点对齐整张地图最外圈格的四个角（从最外圈格算起，不是从最外侧建筑或墙算起） → Enter 应用；之后拖拽与保存都用新映射（覆盖存 out/annotate/NN_quad.json，可一键重置）。
6. 全部阵标完看 out/annotate/summary.json（每阵建筑数 / 人工修改次数 / 耗时）。
