# 四角标注工具（给自动标定模型造数据）

## 启动

    python tools/label_corners/start.py        # 默认 http://127.0.0.1:8781，自动开浏览器

## 操作

1. 页面左侧显示一张阵图；右侧是待标注列表（20 张不同 TH/皮肤的阵型图 + 6 张已有 base.png，共 26 张）。
2. 鼠标依次点 4 个角：**① 上 → ② 右 → ③ 下 → ④ 左**。
3. 口径：**整张 44×44 地图最外圈格的四个角**，不是最外侧建筑/墙。
4. `Backspace` 撤销上一个点；`→` 跳过；`Enter` 保存并下一张。
5. 标注结果写 `out/corners/<图片名>.json`（含 4 点像素坐标），进度显示在左上角。

## 后续（我来做）

标注完成后跑训练：用图片预测 4 角（自动标定），接入 `tools/import_base.py` 替代草地检测，遇到任何皮肤都能自动给出网格。

## 接口

- `GET /api/list` 列表与完成状态；`GET /api/progress` 进度；`GET /img?f=` 图片；
- `POST /api/save` body `{file, quad:[[x,y]×4]}`，返回保存路径。
