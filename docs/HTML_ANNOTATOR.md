## 操作（鼠标）
- **滚轮**：以指针为中心缩放（0.2x ~ 8x）
- **左键拖动**：平移画面（在空白处按住拖动）
- **左键单击**：点四角 / 放建筑
- 靠近角点按住拖动 = 拖角；靠近已放建筑按住拖动 = 挪建筑
- ＋ / － / 适应 按钮、双击放大也可用

## 本版修复

## 功能
- 20 张 TH16 满防阵图（base64 内嵌，单文件离线）
- 四角可拖到图片外；46 类中文；类型列表收起、选完自动收起

- 导出 v2 JSON 到浏览器下载目录；进度存 localStorage
