# 高分辨率截图链路（2026-11-27）

## 已实现

- `tools/capture_hires.py`：ADB 截图（可临时 wm size 提升，结束自动 reset）
- `tools/ldplayer_hires_launch.py`：把雷电实例 0 设为 1920x1080 横屏并启动、连续截图
- 实测：截图输出 1920x1080（out/live/hires/coc_*.png），较 1280x720 建筑像素约 1.5 倍

## 遇到的问题（未解决）

1. 家园截图自动标定不可靠：grass_contour 把 UI 矩形当村庄；草地掩膜菱形四角偏差约半格
2. 门控在家园截图只给 19 个候选（战争截图域 71 个）——家园墙色/光照与训练域有差异
3. adb input tap 在 CoC 内不生效：点「去看看」按钮无响应，无法自动导航到战争地图/侦察界面
