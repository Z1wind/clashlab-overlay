# ClashLab 标注 APK v0.2.5（20 张满防阵型 · 初学者版）

## v0.2.5 新增

- **双击放大**：双击图面在 1x / 2x 切换（配 ＋/－/适应 与双指缩放）
- **全清空**：双段确认清空全部 20 张进度（在「清空」右侧）

## 使用
1. 安装后首次允许文件权限
2. 点四角（黄点可拖、双击放大）→ 选建筑 → 点中心
3. 同视角多张可点「沿上张四角」
4. 标 10 张左右 →「导出全部」→ 发我 annot_all.json

## 已知限制
- Android 9 导出可能落 App 私有目录；Android 10+ 正常进「下载」。
