# ClashLab 标注 APK（20 张满防阵型 · 初学者版）

## 包含内容
- 20 张 TH16 满防阵型图（来源 clashofclans-layouts.com 原图，统一 1600 宽，共 8.23 MB）
- 初学者标注流程：① 点四个角 → ② 选建筑类型 → ③ 点建筑中心；点已标建筑 = 删除
- 首次打开自动弹 30 秒教程；每一步有高亮步骤条
- 自动保存（localStorage），切图/重启不丢；复制上一张进度不需要
- 导出：本张 JSON / 全部 20 张 JSON；保存到「下载」；旧 Android 自动兜底到 App 私有目录
- 双段确认「清空本张」（防误触，6 秒内点两次）。

## 安装
1. 把 `ClashLabAnnotator_20bases_v0.2.0.apk` 传到手机安装（允许未知来源）。
2. 首次打开若弹「允许访问文件」→ 点允许（导出 JSON 需要）。
3. 教程 → 按 ①②③ 点即可；点完一张点「下一张」。
4. 标完点「导出全部」，JSON 在 下载/annot_all.json。

## 实测记录（LDPlayer Android 9，1920x1080）
- 安装成功；首启教程自动弹出；四角标定→网格出现
