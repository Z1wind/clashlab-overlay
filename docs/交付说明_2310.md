# ClashOverlay 交付说明（2026-11-23 23:10 版）

> 本文配合 `dist\ClashOverlay.exe`（88,492,303 B / 22:53:23）使用。
> 这版**已修掉面板绘制崩溃**，可以正常跑；视觉问题与面板位置问题尚未改完，见"已知问题"。

## 一、怎么启动

双击 `dist\ClashOverlay.exe` 即可，**不需要命令行参数**。

- 单屏环境下已自动放行（不必再加 `--allow-primary`），日志会打一条 WARN。
- 启动后默认进 **HUD 模式**：贴在雷电客户区，全穿透，鼠标可正常操作游戏。
- 需要看面板时切 **PANEL 模式**：面板可交互，鼠标点击有效。

## 二、键位（设置页可改）

| 动作 | 默认键 | 说明 |
|---|---|---|
| 切换 HUD / PANEL | `F8` | **注意：F8 与雷电"视频录制"撞键**，建议改成 F6 |
| 截图/采集 | `F9` | 与雷电"操作录制"撞键，建议改 |
| 实况 | `F7` | 实测可注入（down 50ms up） |
| 重载 | `F12` | |
| 回 HUD | `ESC` | |

改键位置：面板 → 设置页 → 五行改键（中文名 / 当前键 / [改键] / [清除]）。
按 [改键] 后按新键，`ESC` 取消；与已占用键冲突会红字拒绝；命中雷电自家键给黄色警告但允许。
落盘 `config\overlay_keys.json`，改完即时生效。

**引擎切换（本地 / 大模型）不走热键，只在面板上点按钮。**

## 三、两种模式干什么

**本地模式**：读 `out\prebattle\info.json` 的 `exposed`，按 dps 降序分三档（前 3 = rank3、4–6 = rank2、其余 rank1）。
—— 注意：数据源当前是 `layout_id=th13_sample.json` 的示例阵，不是实时识别出来的。截图自动识别建筑类型已被实测证伪（信号与背景不可分），不要指望。

**大模型模式**：把阵型数据 + 知识库检索到的参考战术卡发给 `deepseek-v4.1-flash`，输出三段【威胁排序】【进攻路线】【兵种与法术】。
—— 需联网；模型偶发空 content，已带 3 次重试（每次 sleep 1.2s）。实测 9–20s 出结果。

## 四、已知问题（都不影响"能跑"，但影响体验）

1. **PANEL 面板压在游戏画面右侧约 440px**（客户区 1000 宽里的 44%）。要移到雷电窗口外的桌面空白区，**还没做** —— 这是下一步第一优先。
2. **页签仍是亮绿、选中行仍是红字红条**。你要的"选中反而更难读"没解决。A 方案（石墨底 `#161A20` + 冷白正文 + 琥珀 `#E8A33D`）的 tokens 已定，但没落到代码。
3. **面板底板半透明**，后面的窗口内容会透上来（能看到豆包、浏览器文字）。
4. HUD 左下角可能画出策略正文（`[k001] 雷龙第1批×3…`），来源待查。
5. 1920×1080 大尺寸**实机未验**，只有离屏通过。
6. F9 / F11 未逐键实测（发了会点亮雷电录屏窗）。

## 五、这版有据可查的成果（与 EXE 无关的部分，都在仓库里）
